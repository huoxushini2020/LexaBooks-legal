Support

Lexa · Technical support for iPhone, iPad, and Mac

English

Need help with Lexa (opening EPUB / PDF / TXT, bookshelf, iCloud import, tabs on Mac, translate, speak, copy, share, or reading progress)?

  • Open a support request: GitHub Issues
  • Include your OS version (iOS / iPadOS / macOS), device model, app version, and steps to reproduce.

Quick tips

  • Import books with “+” / Open, or on Mac drag files into the Lexa window.
  • If iCloud is available, choose “iCloud” or “This Device” when importing.
  • For TXT covers, place an image with the same filename beside the text file (e.g. Book.jpg next to Book.txt).
  • Use the mouse/text tool (not the hand tool) to select text and show the action menu.

中文 · 技术支持

如在使用 Lexa 时遇到问题（打开 EPUB / PDF / TXT、书架、iCloud 导入、Mac 多标签、选区翻译 / 朗读、阅读进度等），请：

  • 提交反馈：GitHub Issues
  • 请注明系统版本（iOS / iPadOS / macOS）、机型、应用版本与复现步骤。

使用提示

  • 通过「+」/ 打开导入书籍；Mac 可将文件拖入 Lexa 窗口。
  • 若已登录 iCloud，导入时可选择「iCloud」或「本机」。
  • TXT 封面：将同名图片放在文本旁（如 Book.txt 旁放 Book.jpg）。
  • 选中文字请使用鼠标/选字工具（不要用手形工具），即可出现操作菜单。
